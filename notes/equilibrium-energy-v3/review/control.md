# Контрольные формулы (независимый вывод супервизора)

Скрипт символьной проверки: `control_check.py`.

## Магнитное кольцо, исходная система

| Формула | Статус |
|---|---|
| η₀ = α₀ − 1/γ² | подтверждена (ряд (C/C_s)(v_s/v)) |
| η₁ = α₁ − α₀/γ² + (1 + β²/2)/γ² | подтверждена |
| w = δ + δ²/(2γ²) | подтверждена |
| δ = δ_eq + A cos ψ + (η₁A²/6η₀) cos 2ψ, δ_eq = −η₁A²/(2η₀) | **исправлена** (см. issues.md, п. 1): решение уравнения с c₂ подтверждено Линдштедтом, но удар зазора точен в w, а не в δ. Верно: w = w_eq + A cos ψ + (η̃₁A²/6η₀) cos 2ψ, η̃₁ = η₁ − η₀/(2γ²); δ_eq = −η₁A²/(2η₀) не меняется |
| Ω/ω_s = 1 − (5/12)(η₁A/η₀)² | **исправлена**: Ω/ω_s = 1 − (5/12)(η̃₁A/η₀)² |
| (δ_max − δ_min)/2 = A (вторая гармоника полуразмах не меняет) | подтверждена |
| φ = (ω_rf/Ω)[η₀A sin ψ + (η₁A²/3) sin 2ψ] | подтверждена (⟨τ⟩ = O(A³), коэффициент τ при cos 2ψ равен 2η₁A²/3) |
| w_eq = −(η₁ − η₀/(2γ²))A²/(2η₀) | подтверждена |

Устойчивость: δ̈ = K cos φ_s ω_rf η₀ δ, при cos φ_s = −sgn η₀ коэффициент равен −Kω_rf|η₀| = −ω_s². Подтверждено.

Точность условия ⟨τ⟩ = 0: φ_{n+1} − φ_n = 2πhτ_n, φ периодична → Σ τ_n = 0 за период. Среднее — по оборотам. Подтверждено.

## Бетатронное запаздывание (магнитное)

| Формула | Статус |
|---|---|
| ΔT_β/T_s = ΔL_β/C_s (скорость на траектории постоянна) | подтверждена |
| ⟨x′²⟩ = J_x γ_x | подтверждена (x′ = −√(2J/β)(sin ψ + α cos ψ)) |
| Λ = (1/C)(J_x/2·∮γ_x + J_y/2·∮γ_y + ⟨∮x_nl/ρ⟩) | подтверждена |
| β = const: Λ = π(J_xν_x + J_yν_y)/C | подтверждена |
| Λ = −(2π/C)(J_xξ_x + J_yξ_y) | подтверждена: знак проверен на фокусирующем канале (ξ = −ν/2 даёт πJν); соотношение следует из симплектичности и верно в первом порядке по J, ξ — полная хроматичность по импульсу |

## Второй порядок по фазе

| Формула | Статус |
|---|---|
| ⟨δ²⟩ = A²[E(k)/K(k) − 1 + k²]/k², k = sin(φ̂/2) (маятник, A — полуразмах) | подтверждена: совпадает с прямой квадратурой |

## Электростатика

Скрипты: `control_check_es.py`, `control_check_es_lambda.py`. Предположения: изгиб только электрический (1/ρ_E = 1/ρ), фокусировка вне дефлекторов магнитная (потенциал вне дефлекторов равен нулю), индекс поля n одинаков во всех дефлекторах.

| Формула | Статус |
|---|---|
| ψ = qΦ/(p_s v_s) = ξ − (n/2)ξ² + ((n−1)/2)η², ξ = x/ρ, η = y/ρ | подтверждена (уравнение Лапласа в криволинейных координатах: c₁ + 2c₂ + 2c₃ = 0; знак из qE₀ = p_s v_s/ρ) |
| Локальный γ = γ_s(1 + β_s²(w − ψ)) | точное тождество (E = E_s + β_s²E_s w, qΦ = β_s²E_s ψ) |
| v_s/v = 1 − u/γ² + 3u²/(2γ²), u = w − ψ | подтверждена |
| η₀ = α₀(1 + 1/γ²) − 1/γ², α₀ = ⟨D/ρ⟩ | подтверждена |
| η₁ = ⟨D′²⟩/2 + (1 + 1/γ²)⟨D₂/ρ⟩ + ((5 − n)/(2γ²))⟨(D/ρ)²⟩ − 4α₀/γ² + (3γ² − 1)/(2γ⁴) | подтверждена; совпадает со старой es-eta1, но в тексте пишется сразу в этом явном виде |
| Проверка на кольце из одного дефлектора (точные круговые орбиты, n = 1, 3/2, 2, γ = 5/4, 5/3) | общая формула совпадает точно (рационально); n = 1: η₀ = 1, η₁ = (γ²+1)/(2γ²); n = 2: η₀ = γ²+2, η₁ = (9γ⁴+7γ²+2)/(2γ²) |
| Λ = (1/C)∮[(1 + 1/γ²)⟨x_nl⟩/ρ + ⟨x′² + y′²⟩/2 + ((5 − n)/(2γ²))⟨x_β²⟩/ρ² + ((n − 1)/(2γ²))⟨y²⟩/ρ²] ds | подтверждена: алгебраически; и численно на кольце из одного дефлектора (орбиты = формула до 10⁻⁶) |
| Λ = −(2π/C)(J_xξ_x + J_yξ_y), ξ = dν/dδ (δ определено через полную энергию) | подтверждена численно для n = 1, 3/2, 2 (симплектическое соотношение работает и в электростатике) |
| n = 1: Λ = 0; n = 2: Λ = −β²X | подтверждены |
| ⟨γ − γ_s⟩/(β_s²γ_s) = ⟨w⟩ − ⟨ψ⟩; на дисперсионной орбите (1 − α₀)δ в первом порядке | подтверждена (следует из точного тождества для γ) |

Замечание для текста: ν_x² = 3 − n − β² для кольца из одного дефлектора подтверждено численно; в текст не входит.

## Сомнения

Нет. Все контрольные формулы глав 1–5 подтверждены. Единственное, что нужно явно оговорить в тексте главы 4: фокусирующие элементы вне дефлекторов считаются магнитными. Электростатические квадруполи добавили бы члены от изменения скорости в их потенциале.
