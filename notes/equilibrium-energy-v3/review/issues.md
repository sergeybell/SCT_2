# Журнал проблем и сомнений

## 1. Удар зазора в переменной δ (исправлено)

**Где:** контрольные формулы плана и глава 1 первой версии Grok; то же было во всех прежних заметках.

**Суть:** второе уравнение писалось как dδ/dt = K cos φ_s sin φ, то есть с dE = β_s²E_s dδ. За оборот зазор точно меняет энергию, а Δδ = ΔE/(p_s v) = ΔE/(β_s²E_s)·(v_s/v), v_s/v = 1 − δ/γ_s² + …. Отброшенный множитель даёт в уравнении для δ члены порядка A² — того же порядка, что η₁δ².

**Что не меняется:** δ_eq = −η₁⟨δ²⟩/η₀ следует только из первого уравнения (⟨τ⟩ = 0), поэтому δ_eq = −η₁A²/(2η₀) и w_eq верны.

**Что менялось:** вторая гармоника и частота. Правильно (переменная w, удар точный):
- τ = η₀w + η̃₁w², η̃₁ = η₁ − η₀/(2γ_s²);
- w(t) = w_eq + A cos ψ + (η̃₁A²/6η₀) cos 2ψ, w_eq = −η̃₁A²/(2η₀);
- Ω/ω_s = 1 − (5/12)(η̃₁A/η₀)²;
- в импульсе: вторая гармоника δ равна η₁A²/(6η₀) − A²/(3γ_s²), а не η₁A²/(6η₀).

**Проверка:** `control_check_kick.py` — интегрирование точной системы в w: среднее δ, вторая гармоника и частота совпадают с исправленными формулами (частота — с точностью до члена −φ̂²/16).

**Решение:** система продольных уравнений пишется в (φ, w); δ_eq получается пересчётом δ = w − w²/(2γ_s²). На главу 3 (поправка φ̂²/32 к δ_eq) не влияет.

## 2. Множитель (1 − φ̂²/32) у слагаемого A²/(4γ_s²) в главе 3 (исправлено)

**Где:** задание Grok на главу 3, формула w_eq с Λ.

**Суть:** в задании было w_eq = δ_eq + A²/(4γ_s²). Связь w_eq = δ_eq + ⟨δ²⟩/(2γ_s²) с ⟨δ²⟩ = (A²/2)(1 − φ̂²/32) требует того же множителя. Grok заметил расхождение; в тексте стоит множитель, обе формы для w_eq совпадают.

## 3. Поправка к частоте Ω порядка A² (снята из текста)

**Где:** прежние формулы Ω/ω_s = 1 − (5/12)(η̃₁A/η₀)² в главах 1–3.

**Суть:** при ряде τ, оборванном на δ², поправка порядка δ_m² не определена: такой же вклад дают член η₂δ³ в τ, член δ² в множителе v_s/v удара зазора и член φ³ в sin φ. Численная проверка (`control_check_delta.py`): системы в δ и в w, эквивалентные до второго порядка, дают разные Ω на этом порядке (−2.6·10⁻⁵ против −3.5·10⁻⁵ при δ_m = 0.004), а δ_eq и вторая гармоника совпадают. Слепой вывод Grok (глава 1 в δ) пришёл к тому же выводу независимо.

**Решение:** формула частоты из текста убрана; на δ_eq она не влияет. Перекрёстный член −η̃₁Λ/η₀² первого порядка по Λ численно подтверждён, но он того же порядка, что и отброшенные члены, поэтому тоже не приводится.

## 4. Ревизия в переменной δ (слепые выводы Grok)

Главы переписаны в δ по постановке без готовых ответов; результаты Grok сверялись с контрольными формулами супервизора. Глава 1 и приложение A.1: совпадение по η₀, η₁, уравнению для δ (с членом −δ̇²/γ_s²), второй гармонике η₁δ_m²/(6η₀) − δ_m²/(3γ_s²), δ_eq, фазе и γ_eff = γ_s + β_s²γ_sδ_eq + β_s²δ_m²/(4γ_s).

- Глава 2: Λ = (1/C_s)[J_x/2∮γ_x + J_y/2∮γ_y + ∮⟨x_nl⟩/ρ], при постоянных β — π(J_xν_x + J_yν_y)/C_s, форма через хроматичность −(2π/C_s)(J_xξ_x + J_yξ_y) (симплектическое отображение; Grok дополнительно проверил ∮γ = −4πξ на FODO). Совпадает.
- Глава 3 и A.2: ⟨δ²⟩ = (δ_m²/2)(1 − φ̂²/32), точная форма через E(k)/K(k), множитель не действует на Λ. Совпадает.
- Глава 4: η₀^E = (1 + 1/γ²)α₀ − 1/γ², η₁^E с членом (5 − n)/(2γ²)⟨(D/ρ)²⟩ и −4α₀/γ². Совпадает (Grok проверял точными решениями для одного дефлектора). Сомнение Grok: γ_eff в ЭС-кольце — среднее вне дефлекторов; внутри дефлектора локальный γ меньше на β²γ_s⟨ψ⟩. В тексте это оговорено.
- Глава 5: Λ^E с членами (1 + 1/γ²)⟨x_nl⟩/ρ, (5 − n)/(2γ²)⟨x_β²⟩/ρ², (n − 1)/(2γ²)⟨y_β²⟩/ρ² совпадает с контролем. Хроматическая форма Λ^E = −(2π/C)(J_xξ_x^E + J_yξ_y^E) подтверждена прямым счётом периода на кольце из одного дефлектора (E_r ∝ r⁻ⁿ, ν_x² = 2 − n + 1/γ², ν_y² = n − 1, ξ_y^E = 0) и симплектическим аргументом; равенство выполняется только с учётом сдвига ⟨x_nl⟩. **Сомнение:** ЭС-кольцо с дрейфами и квадруполями прямым интегрированием не проверено.
- Глава 6: уравнение дисперсии в дефлекторе D″ + (2 − n + 1/γ²)D/ρ² = (1 + 1/γ²)/ρ; разности η^E − η^M и Λ^E − Λ^form проверены. Коррекция полной хроматичности (по δ вне дефлекторов) снимает Λ в δ_eq в обоих кольцах; остаётся −η₁δ_m²/(2η₀), а η₁ сдвигается секступолями через D₂ — **величина сдвига не вычислена**.
- Формула коллег γ_eff = γ_s + β²γ_sδ_eq — часть ⟨γ⟩ вне дефлекторов без β²⟨δ²⟩/(2γ_s); отношение членов |η₀|/(2|η₁|γ²). Внутри дефлектора средний локальный γ меньше на β²γ_s⟨ψ⟩. Фраза главы 1 «γ_eff определяет частоту прецессии» заменена: связь со спином в записке не выводится.
- Глава 2: уточнено, что ∮γ и ∮⟨x_nl⟩/ρ по отдельности не равны натуральной хроматичности и вкладу секступолей — равны только суммы.
- Объём: подробные выводы по запросу увеличили текст до ~40 стр.; избыточные проверки (линейная хроматичность, ряды эллиптических интегралов, повторный вывод ОДУ с Λ) сокращены.

## 5. Правки по замечаниям (14.10.2026)

Пункты 4 выше про кольцо из одного дефлектора, симплектический аргумент и Λ^form устарели: эти части из текста убраны.

- Термины: «зазор» → резонатор, «толчок/удар» → приращение энергии/импульса, «гладкая система» → непрерывное приближение, «изгиб» → поворот. Пределы γ_s → ∞, гамильтонианы, внешние произведения и фокусирующие каналы из текста удалены.
- Глава 2: τ через длину, C/C_s = 1 + α₀δ + α₁δ² + Λ и (v_s/v)Λ = Λ − Λδ/γ² + …; хроматичность через удлинение (функция Грина, ∮x_nl/ρ = ∮⟨F^x⟩D₁, ∮Kβ = ∮γ). Явный интеграл верен для тонких поворотов; равенство Λ = −2πJξ/C_s с полной хроматичностью проверено на FODO с секторными диполями (`_check_ch2_sector_multiturn.py`: 10⁻⁴ по x, 10⁻⁸ по y). **Методическая ловушка:** однооборотное усреднение по фазе запуска на линейном эллипсе даёт ложное расхождение ~10 % при геометрических нелинейностях; правильно — одна частица, много оборотов, окно Ханна.
- Глава 4: одна цепочка γ_loc = γ_out − β²γ_sψ → v_s/v; (129) при ψ = 0 совпадает с (9); произведение пути и скорости выписано явно; уравнение D₁ в дефлекторе перенесено из гл. 6 и выведено (sympy по точному движению в E_r ∝ r⁻ⁿ). Ряды и коэффициенты при δ² перепроверены супервизором.
- Глава 5: рабочий интеграл Λ^E выведен через время пролёта; ξ^E через жёсткости (2 − n + 1/γ²)/ρ², (n − 1)/ρ². Равенство Λ^E = −2πJξ^E/C_s проверено численно на периодической ячейке (дефлекторы с жёстким краем, дрейфы, магнитные квадруполи, n = 1,2; 1,8; с секступолями при n = 1,5): 10⁻⁷ по y, 10⁻⁴…10⁻³ по x (`_check_ch5_chrom.py`). **Сомнение:** почленное аналитическое сравнение по x не замкнуто (остаток (∂K_x/∂δ)_{x=0} + K_x + (5−n)/(γ²ρ²), члены x′² в силе, 2(n−1)/ρ³, стык дефлектора). Ожидаемое обоснование — сопряжённость времени и полной энергии — в тексте названо, но не выведено.
- Глава 6: без Λ^form, γ_s → ∞ и кольца из одного дефлектора; (217) — оценка при постоянных β; формулы η^E − η^M и Λ^E − геометрическая часть сверены в sympy.
- **Открыто:** сдвиг η₁ секступолями через D₂ не вычислен; краевое поле дефлектора в проверках не учитывалось.
