# OptiM — эталон

* `magnetic_2_md.opt` — копия утверждённой решётки `C:\GIT_REPOS\SCT_2\lattice\magnetic_2_md.opt`.
* OptiM — только GUI (`C:\Program Files\OptiMX-x86-64\optimx64.exe`), из скрипта не запускается.
  `run_optim.bat` только открывает файл; результат Twiss переписан вручную в `output/optim_reference.txt`
  (значения, полученные пользователем).
* Что считается: линейная оптика замкнутого кольца, Qx, Qy, alpha_c, eta, **натуральная** хроматичность
  первого порядка ξ = dQ/dδ, δ = dp/p (секступоли SF1, SF2, SD = 0).
* Диполи BM: элемент `B` без краевых углов — секторный магнит, R = 13.5712 м, 22.5°.

Результат: Qx=2.46172, Qy=2.46134, alpha_c=0.23047, eta=-0.533689, ξx=-1.46153, ξy=-1.81705.

**Twiss вдоль кольца из OptiM отсутствует** (только GUI, экспорта нет). Чтобы добавить в сравнение: в OptiM открыть окно Twiss и сохранить таблицу (β_x, β_y, D_x по s) в `output/optim_twiss.txt` — ноутбук можно дополнить её чтением.
