# fringe_comparison — краевые поля: COSY FR 0/3 против всех моделей Bell, хроматичность высших порядков

Решётка magnetic_2_md. GAP = полу-апертура (COSY); Bell: Enge(gap = 2*GAP). Краевые поля секступолей не учитываются нигде.

| `COSY/chrom_cmp.fox` | OV 7 2 1 + TP MU для (FD,FQ) = (0,0),(3,0),(0,3),(3,3) × GAP 0.05/0.025/0.0125/0.00625 → `output/cosy_mu_series.csv` (`MU\|(0&0&0&0&k)`, k = 0..6, коэффициенты Тейлора по δK = ΔK/K) |

Нормировка: COSY даёт Q(δK) = Σ μ_k δK^k; пересчёт δK(δ) точный (ряд до δ⁶), ξ_n = dⁿQ/dδⁿ = n! q_n. Bell `xi2` = d²Q/dδ².
Ограничение Bell: MAP_ORDER = 3 (JET_ORDER = 4) ⇒ надёжны только Q, ξ1, ξ2.

Замечание (баг Bell, не исправлялся): кэш краевых карт (`_ECACHE` в fringe.jl) использует ключ `repr(model)`, а `repr(Tabulated)` = "Tabulated(N points)" —
таблицы одной длины для разных gap давали одинаковый результат. Обход в run.jl: разное число точек на каждый GAP.

## Предложение: хроматичность произвольного порядка в Bell (не реализовано)
1. Сделать порядок карты параметром (`JetSpace(order = N+1)` вместо констант `JET_ORDER`/`MAP_ORDER`), протащить его через `ring_lie_factor`/`factor_to_map`/edge-карты (Dragt–Finn факторизация до порядка N, генераторы краёв и soft-edge гамильтонианы уже полиномиальные — их надо лишь не обрезать на степени 4).
2. Параметрическая (по δ) нормальная форма вместо конечных разностей: (а) неподвижная точка u(δ) как DA-ряд по δ (Ньютон в DA: u ← u − (J−I)⁻¹(M(u,δ) − u), каждая итерация удваивает верный порядок); (б) сдвиг карты на u(δ), линейная часть R(δ) — матрица DA-рядов по δ; (в) Q(δ) = arccos(tr R_xx(δ)/2)/2π как DA-функция (с выбором ветви по знаку R12 при δ = 0) или через собственные числа; (г) выдавать q_n и ξ_n = n! q_n до порядка N−1 — это то же, что TP у COSY.
3. Альтернатива без перестройки карт: tracking на замкнутой орбите при наборе δ (Чебышёвские узлы) с точной (не обрезанной) поэлементной картой и фит — пригодно для проверки, но точность высших коэффициентов ограничена.
4. Тест: NoEdge против COSY FR0 OV 7 (`cosy_q_delta.csv` здесь): ξ3 ≈ −26.88 / −41.39, ξ4 ≈ 261.5 / 263.5, ξ5 ≈ −4160 / −4722 (x / y).
5. Для квадруполей добавить SoftEdge (Enge с апертурой) — иначе нельзя повторить COSY FR 3 по Q и ξ1 при больших апертурах.

## Источник дипольного расхождения (single_dipole/, раздел 9 ноутбука)
- Линейные карты одиночного BM (FR3 vs SoftEdge Enge) совпадают до 1e-7 ⇒ масштаб/коэффициенты Энге, EFB, FINT одинаковы.
- Возмущение по коэффициентам карты BM воспроизводит Δξ кольца до 1 %; разница — в геометрических членах 2-го порядка, работающих через дисперсию.
- Горизонталь: член Bell `b2 = h0 F'' θ²` (прямая EFB, видимая с изогнутой орбиты, H ∋ b2(x³−3xy²)/6), K2L = −2.0e-5 м⁻² на край при GAP 5 см (∝ GAP),
  даёт Δξx = −2.92e-3 против наблюдаемых −2.89e-3. У COSY FR3 (px|x²), (px|xa), (x|x²) BM нулевые (≤1e-9).
- Вертикаль: b2 даёт +2.0e-3, наблюдается +1.0e-3 (ровно половина): в COSY есть член ∝ xy в вертикальной силе с половинной силой.
- Предложение для Bell: (1) флаг включения b2 (и b1-членов от θ) в `SoftEdge`; (2) проверить Максвелл-согласованность разложения в изогнутой системе
  (соотношение x²- и xy-частей при h ≠ 0); (3) арбитр — трекинг через 3D-поле (Tabulated/расчётная карта поля) или независимый код
  с явной моделью поля секторного магнита; не подгонять под COSY вслепую.
- **Разбор исходника COSY (cosy.fox 10.2, раздел 9.5 ноутбука):** BENDFF3 (стр. 3325) — поле B0·Enge(декартово расстояние до прямой EFB / 2D) (BENDIST 2593, ENGESIDES 2575, DIST 2561),
  вне плоскости — Лаплас в изогнутых координатах с метрикой 1+hx (POFF 2501). Геометрия та же, что у Bell; в Bell `fringe_hamiltonian` нет множителя (1+hx)
  при b1/b2, теряется член h·b1: ∫h b1 = −½∫b2 (проверено численно, отношение 1.000) ⇒ правильно: горизонтальный секступоль = 0, вертикальный = ½ b2.
  Прогноз после исправления: Bell − COSY = +3.6e-5 (ξx), −5e-6 (ξy) при 5 см. Исправление: H += h·b1·(x³/3 − x y²/2) или A_s как в COSY POFF.

## Хроматичность высших порядков из пути потока Ли (разд. 11 блокнота)
`BELL/flow_chrom.jl` (`julia --project=BELL BELL/flow_chrom.jl`, ~25 с) → `BELL/output/flow_xi.csv`, `flow_chrom.log`;
в блокноте - `flow_xi_vs_cosy.csv`, `flow_xi_vs_cosy.png`. Функция ядра Bell `chromaticity_series(lat, N)`:
замкнутая орбита $u(\delta)$ в DA, линейная часть на орбите $R(\delta)$, $Q=\arccos(\operatorname{tr}R/2)/2\pi$ в DA - без конечных разностей,
$\xi_n=n!q_n$ до $n=N-1$. Только NoEdge/FR0 (краевые поля в пути потока не реализованы).
* Bell и COSY считают с одинаковыми данными: дейтрон 1875.61294257 МэВ (Bell `DEUTERON`; COSY `RP EK 1875.61294257/AMUMEV 1` в `../COSY/lattice_md.fox`), $W=270$ МэВ, угол BM ровно $\pi/8$ (`.bell` из `convert_optim(...; close_ring = true)`). Bell (поток, $N=8$) − COSY FR0, отн.: $Q_0$ $3\cdot10^{-15}$, $\xi_1$ $1\cdot10^{-13}$ / $3\cdot10^{-14}$ ($x$/$y$), $\xi_2$ $1.5\cdot10^{-12}$ / $1.1\cdot10^{-12}$, $\xi_3$ $6\cdot10^{-11}$ / $4\cdot10^{-11}$, $\xi_4$ $1.0\cdot10^{-9}$ / $1.4\cdot10^{-9}$, $\xi_5$ $1.2\cdot10^{-8}$ / $2.4\cdot10^{-8}$ ($\xi_6$ COSY при OV 7 ненадёжен, $6\cdot10^{-7}$).
* Прежний остаток $\sim2\cdot10^{-8}$ (округлённый угол BM в `.bell` и масса COSY 1875.612945 МэВ) устранён; рост разности с $n$ - со стороны COSY (OV 7, пересчёт $\delta_K\to\delta$), ряд Bell от $N$ не зависит.
* Старый остаток $\xi_1\approx-2\cdot10^{-6}$ (`summary_xi1.csv`, NoEdge − FR0) остаётся: это артефакт центральной разности `chromaticity_orders` по карте порядка 3 ($q_3^{\rm trunc}dd^2$), не физика.
