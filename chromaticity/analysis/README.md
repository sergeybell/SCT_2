# analysis — сравнение хроматичности

* `analysis.ipynb` (выполнен, выходы сохранены) читает `../*/output/*` и строит таблицу Qx, Qy, alpha_c, eta, ξx, ξy
  в едином определении **ξ = dQ/dδ, δ = dp/p**, натуральная, 1-й порядок; в строках указаны программа и метод.
* `exact_hamiltonian_check.py` → `.out` — независимая проверка: RK4-интегрирование точного гамильтониана
  (секторный диполь с фиксированным полем, жёсткий край без fringe, квадруполи, дрейфы), замкнутая орбита при δ,
  тюны якобиана, центральная разность ±1e-4.
* `make_notebook.py` генерирует ноутбук; `run_analysis.bat` — всё заново.

Итог: Qx, Qy, alpha_c, eta, ξx совпадают везде. ξy: OptiM / MAD-X / PTC = −1.8171; BELL / COSY / Python (только тело магнита) = −2.2255.

Итог по ξy: −1.817 (OptiM/MAD-X/PTC) отличается от −2.2255 (BELL/COSY FR 0) на краевой член жёсткого края
(+0.408, Δp_y = ∓h x' y), см. раздел «Почему ξy» в `analysis.ipynb` и `chrom_terms.py`.
