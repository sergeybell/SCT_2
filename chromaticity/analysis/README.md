# analysis — сравнение хроматичности и Twiss

* `analysis.ipynb` (выполнен, выходы сохранены; генерируется `make_notebook.py`):
  1. каждый запуск отдельно — команда/файл, сырой вывод (строки файлов как есть), что берётся, пересчёт к ξ = dQ/d(dp/p), результат;
  2. сводная таблица; 3. Twiss-функции BELL / COSY / MAD-X / PTC (наложение и разности относительно MAD-X; OptiM — только начальная точка);
  4. почему ξy различается: вывод из гамильтониана, член за членом, проверки (+0.408 = краевой член жёсткого края).
* `exact_hamiltonian_check.py [1]` — RK4 точного гамильтониана (только тело; с аргументом 1 — ещё и с краевыми ударами).
* `chrom_terms.py` — численные значения членов A, C, E, F.
* `run_analysis.bat` — пересчитать всё.

Итог: Qx, Qy, alpha_c, eta, ξx совпадают везде; Twiss совпадают до ≤1.1e-7 м. ξy: −1.817 (OptiM/MAD-X/PTC, жёсткий край)
vs −2.2255 (BELL, COSY FR 0 — только тело); разница — краевой член Δp_y = ∓h x' y.
