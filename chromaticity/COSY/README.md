## Переменная COSY и пересчёт
COSY использует δ_K = ΔK/K (K — кинетическая энергия). Так как dK = dE = β²E·dp/p,
δ_K = (E/K)β²δ_p = (γ+1)/γ·δ_p = (1+1/γ)δ_p. Поэтому
**ξ_p = dQ/dδ_p = (1+1/γ)·dQ/dδ_K**, (1+1/γ) = 1.874162. В файлах приведены оба: `*_raw` (по δ_K) и `xi_*_p`.

## Две постановки
* `chrom_ov321.fox` — **OV 3 2 1**: 2 фазовые плоскости + 1 параметр; `RP EK*PARA(1)` — энергия является
  DA-параметром (в этой версии PARA(1) имеет постоянную часть 1, коэффициент при параметре = δ_K).
  `TP` даёт тюны как функции параметра; ξ = (MU|δ_K)·(1+1/γ). → `output/cosy_ov321.txt`.
* `chrom_ov330.fox` — **OV 3 3 0**: полное 6D-отображение, δ_K — 6-я координата, поля фиксированы.
  `TP` здесь неприменим (COSY: «ERROR in GT, unrepresentable map» — нет продольных колебаний), поэтому
  ξ читается из коэффициентов отображения на замкнутой орбите вне энергии:
  dTr_x/dδ_K = (x|xδ)+(a|aδ)+2(x|xx)D+(x|xa)D'+(a|xa)D+2(a|aa)D', аналогично для y,
  dQ/dδ_K = −dTr/dδ_K/(4π sin2πQ). Там же D, eta = −(l|δ_K)_closed/C·(1+1/γ)², alpha_c = eta + 1/γ².
  → `output/cosy_ov330.txt`.

## Почему TP не работает в OV 3 3 0 и что дают коэффициенты (дополнение)
* `map_ov330.fox` → `output/map_ov330.txt` (PM, 3-й порядок) и `output/map_ov330_full.txt` (все коэффициенты MAP(1..6), полная точность).
* `ov330_map_analysis.py` → `output/ov330_map_analysis.txt` (+ `.json`): таблица линейного 6x6 блока и хроматических членов 2-го порядка,
  затем хроматичность «как в других программах»:
  1. замкнутая орбита поперечного отображения при фиксированном δK (Ньютон), якобиан 2x2, Q = acos(Tr/2)/2π, центральная разность ±1e-4;
  2. 4D-отображение с δK как параметром (l отброшена — x,a,y,b от l не зависят без ВЧ): dM/dδK = (i|j δK) + подача с замкнутой орбиты,
     dQ/dδK = −dTr/(4π sin μ). Оба дают ξ = −1.461536 / −2.225485 — то же, что OV 3 2 1 TP. Пересчёт ×(1+1/γ).
* Причина ошибки «GT, unrepresentable map»: без ВЧ продольный блок = [[1, (l|δK)=17.836 м],[0,1]] — жорданова клетка,
  собственные числа 1, 1 (не пара e^{±iμ}). Собственные числа 6x6: e^{±2πi·0.461720}, e^{±2πi·0.461337}, 1, 1.
  TP/TS строят нормальную форму 6D и требуют три пары комплексно-сопряжённых чисел на окружности — их нет.
* `rf_tp_ov330.fox` → `output/rf_tp_ov330.txt`: тонкий RF (h=1, f=1.24024 МГц, фаза 0 — устойчива; 180° неустойчива) при V = 100…0.001 кВ.
  TP работает: Qx=0.4617201484, Qy=0.4613373213 (не зависят от V), Qs = 0.004097·√(V/100 кВ).
  Но линейной хроматичности в выходе TP/TS нет: с ВЧ δK больше не инвариант/параметр, а координата синхротронного движения,
  нормальная форма зависит только от амплитуд (TS даёт сдвиги тюнов от амплитуд), ξ1 усредняется по синхротронным колебаниям.
  Поэтому «предел V→0» для ξ через TP не получить; ξ берётся из OV 3 2 1 (δK — параметр) или из коэффициентов 6D-отображения, как выше.
